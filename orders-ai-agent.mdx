The AI agent can read and update your production orders. Ask it which orders are late, how each supplier is doing, or why an order is at risk. You can also tell it to move a date or mark a milestone done, on one order or many.

## Where to use it

Open a regular agent chat: click **New chat** and type your question. Order tools are on automatically when your workspace has Production Order WIP turned on. You don't need to pick a skill.

<Note>
  The Global chat bar doesn't appear on Order pages. Use **New chat** instead.
</Note>

## What answers look like

### A live Orders table

When the answer is a set of orders, the agent shows the same table as the [Orders list](/orders), right in the chat. It's live: it shows the orders that match right now, with the health, milestone bar, and issue for each.

<Frame caption="At-risk orders grouped by supplier, answered in chat.">
  ![Agent answer to Show my at-risk orders grouped by supplier, with a summary callout and an Orders table grouped under Dongyang Lejing Garment Co., Ltd. showing two at-risk orders, plus Save as view and Open in Orders links](/images/wip/ai-orders-table.png)
</Frame>

- Ask for a breakdown ("by supplier", "per status") and the table is grouped, with counts for each group.
- The table shows 10 rows at a time. Click **View 10 more** to see more.
- Click **Save as view** to save the filter as a view tab on the Orders page.
- Click **Open in Orders** to open the same set on the Orders page.
- Click a row to open the [order's details](/order-details).

For one order, the agent shows a one-row table. If you ask about its steps ("What's late on PO 4471?"), it adds a table of each milestone with its plan date, actual date, state, and notes.

### Counts and charts

Ask "how many" or "break down by" and the agent answers with the numbers, as a table or a chart.

<Frame caption="A health breakdown shown as a chart.">
  ![Agent answer with a donut chart of 3 orders by health, 2 at risk and 1 on track, and a short summary below](/images/wip/ai-health-chart.png)
</Frame>

### After a change

After every change, the agent shows a success message with what changed, from the old value to the new one, and the order's new health. For example: `PO-4471 · revised ex-factory 2026-09-28 → 2026-10-03 · health at_risk → watch`. The updated order appears below it.

## Safety and limits

Reading is instant. Before some changes, the agent asks you first:

| Change | Does it ask first? |
| --- | --- |
| One order, an exact value ("Move PO 4471's ex-factory to Oct 3") | No, it goes ahead |
| Several orders, a relative change ("Push everything a week"), or an unclear field (ex-factory or revised ex-factory?) | Yes |
| The same milestone change on many orders | Yes, once. Then it works through all of them and reports which succeeded and which failed |
| Completing more than one order | Yes |
| Cancelling or deleting an order | Always, one order at a time |

The agent can't:

- Apply Inbox proposals. It summarizes them and links you to the [Inbox](/receive-via-inbox), where you click **Apply**.
- Change which orders are in a WIP tracker. Do that on the [WIP tracker](/wip-tracker) page.

<Note>
  Completing and cancelling orders is only possible through the agent today. The Orders pages don't have a button for it.
</Note>
